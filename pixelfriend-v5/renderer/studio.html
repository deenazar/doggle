GLB IMPORT

Create a 3D character

Start with Orbit, or bring a character from your imagination into Toggle.

◕‿◕
Orbit is ready to come home.

A real 3D character with Idle, Walk and Happy animations. Built in, no account needed.

  1. Create your character

    Model in Blender, or generate with a 3D service such as Meshy or Tripo. Image generation alone produces a picture, not a working 3D model. Download a mesh you have permission to use.

    Example prompt: “A friendly small blue-and-white desktop robot, rounded shapes, two arms and two feet, front facing, clean low-poly topology, separate limbs, neutral pose.”
  2. Add movement, if you want

    Rig the character in Blender or your preferred rigging tool. Create clips named Idle, Walk, Happy, Ask, Sleep and Held. Static models also work; Toggle moves them around the desktop without inventing limb animations.

  3. Export a self-contained GLB

    In Blender: File → Export → glTF 2.0 → Format: glTF Binary (.glb). Include materials, embedded textures and animations. Disable Draco / Meshopt compression. Apply transforms; face forward (+Z), feet on the floor. Prefer under 50,000 triangles and 2K textures; file limit is 30 MB.

  4. Preview, personalize, apply

    Choose Upload in Character Studio. Inspect the model and available animation clips, adjust facing direction and character size, then choose Apply to desktop. Toggle keeps a local copy, so the source file can move later.

No hosted 3D generation is connected. This guide and the built-in model work without an AI subscription. FBX, OBJ, ZIP and models with external texture files must first be converted to an embedded GLB.
